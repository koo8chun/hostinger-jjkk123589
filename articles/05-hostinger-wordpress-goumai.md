## 3. 安装 WordPress 后的必做清单

### 3.1 基础设置

- 固定链接改为「文章名」类结构  
- 安装必要语言包  
- 设置时区与站点标题 / 副标题  

### 3.2 安全与登录

- 管理员使用强密码  
- 限制登录尝试（插件或主机侧工具）  
- 仅保留必要管理员账号  

### 3.3 性能

- 开启主机提供的缓存 / LiteSpeed 相关能力（以面板为准）  
- 图片上传前压缩  
- 少装「大而全」插件，功能能合并就合并  

### 3.4 SEO 与转化

- 安装成熟 SEO 插件，填好标题与描述模板  
- 每个关键落地页都有清晰 CTA（询盘 / 加购）  
- 配置 Google Analytics / Search Console（按你的市场选择）  

### 3.5 邮件

独立站询盘依赖邮件可达性。建议：

- 使用企业域名邮箱  
- 配置 SPF / DKIM（按 Hostinger / Titan 指引）  
- 表单通知发到业务同事可及时回复的邮箱
